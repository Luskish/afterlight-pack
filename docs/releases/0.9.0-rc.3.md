# AFTERLIGHT 0.9.0-rc.3

## Changes

- Restores SmartBrainLib to both client and server installs so Occultism clients load correctly.
- Removes LuckPerms and retains FTB Ranks as the single permissions system, resolving the multiplayer login reset.
- Replaces VeinMiner and VeinMiner Hotkey with FTB Ultimine `2101.1.15`.
- Adds Controlling `19.0.5` and Searchables `1.0.2` for keybind searching.
- Adds Lootr `1.11.38.123` so supported loot-table containers provide separate loot for each player.
- Lootr does not add structures or new loot tables. It converts supported structure containers while preserving their existing loot-table content.

## Existing World Notes

- Lootr can automatically convert unopened loot-table containers in the existing world after deployment.
- Containers opened before deployment no longer retain their original loot-table identity, so Lootr cannot reconstruct their original generated loot automatically.
- An operator can use `/lootr custom-chest <target>` on a non-empty supported container to copy its remaining contents into a custom per-player inventory. This does not restore the original loot table.
- Lootr is now a persistent world dependency. Removing it later would remove Lootr-converted containers.
- No chunk pregeneration is included or started by this release.

## Distribution

- Prism remains the recommended launcher and follows the stable Packwiz channel only after RC3 is promoted.
- The CurseForge ZIP and `.mrpack` are friends-only because they can embed third-party JARs.
- CurseForge users must import RC3 as a fresh profile and choose All Files when prompted.
