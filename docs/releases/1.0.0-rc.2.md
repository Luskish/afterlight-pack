# AFTERLIGHT 1.0.0-rc.2

## Hotfix Scope

- Updates AFTERLIGHT Signal from `0.2.0` to `0.2.1`.
- Restores ECHO submit, claim, and pin actions by using FTB Quests' Architectury transport.
- Restores the Signal Reliquary title presentation when Aether's Cumulus menu is installed.
- Makes Slow Fire track Immersive Engineering's Coke Oven formation advancement instead of an unobtainable multiblock item.
- Makes Steel Yourself accept any ingot in the common `c:ingots/steel` tag through FTB Filter System.
- Retains the RC1 story, quest, world, server, launcher, and optimization content.

## Player Update

- Prism users import `AFTERLIGHT-prism-instance.zip` once, then receive later stable Packwiz updates before launch.
- Existing Prism profiles on the stable Packwiz channel receive this update automatically after RC2 reaches `main`.
- CurseForge users import `AFTERLIGHT-curseforge.zip` as a replacement profile.
- The release portal remains `https://rl-labs.org/afterlight/`.
