# Gate of Return

The Gate of Return Core is the final physical assembly of the story campaign. It is crafted on a 7 by 7 Mechanical Crafter monument. Mirrored layouts are rejected.

## Monument Layout

The monument consumes eight of each certified bulk material:

- Create iron sheets
- AE2 logic processors
- PneumaticCraft printed circuit boards
- Immersive Engineering steel ingots

It also consumes five unique completed parts:

- Kinetic Frame
- Industrial Anchor
- Isotopic Core
- Lattice Matrix
- Undercurrent Stabilizer

The Gate Blueprint is consumed as the final authorization token. There is no alternate Modular Machinery Reborn path and no second producer for the Gate core.

## Energy Proof

The one billion FE requirement is a separate quest proof. The Mechanical Crafter recipe does not drain that energy directly. Complete the energy task before treating the monument as ready for activation.

## Acceptance

Automated server validation proves the live recipe, exact layout, output, producer count, and mirror rejection. Manual client visual acceptance still requires a player to confirm the 7 by 7 arrangement in JEI and assemble the monument in a release-candidate client.
