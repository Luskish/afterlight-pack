# Progression Token Recovery

Recovery is for confirmed loss, not progression bypass. Before restoring anything, identify the exact source quest in current or archived team data and preserve the evidence path.

## Eligible Items

An operator may restore at most one lost item for a verified incident. Eligible items are:

- One schematic
- One Deep Vault key
- One Gate blueprint
- One Undercurrent stabilizer precursor
- One Gate output
- One Ascendancy Seal

Do not restore bulk ingredients, duplicate rewards, or speculative losses. If the source quest cannot be identified, stop and investigate the team data before issuing an item.

## Recovery Record

Append every recovery to an immutable recovery log. Never rewrite or delete an earlier entry. Each entry records:

- Timestamp in UTC
- Operator
- Player
- Team
- Quest ID
- Item ID
- Count
- Reason
- Evidence path

The restored count must be one. Record whether the evidence came from current team data or an archived copy, then retain the referenced data with the server incident records.
